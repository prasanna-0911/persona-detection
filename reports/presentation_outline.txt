SLIDE 4: PHASE 1 - DETECTION
──────────────────────────────────────────────────────────────────────────
    Technology: YOLOv5 (Pretrained on COCO)

    Performance:
    • Speed: 30-50 FPS (Real-time ✓)
    • Confidence: >75%
    • False Positives: <5%

    Key Learning:
    • Attempted training from scratch → Failed
    • Reason: Class imbalance (95% background)
    • Solution: Transfer learning


SLIDE 5: PHASE 2 - RE-IDENTIFICATION
──────────────────────────────────────────────────────────────────────────
    Technology: ResNet50 + Triplet Loss

    Dataset: Market-1501
    • 12,936 training images
    • 751 unique identities

    Results:
    ┌────────────────────┬─────────┐
    │ Same Person Sim    │ 0.912   │
    │ Different Person   │ 0.078   │
    │ Separation Gap     │ 0.834   │ ← EXCELLENT!
    └────────────────────┴─────────┘


SLIDE 6: PHASE 3 - TRACKING
──────────────────────────────────────────────────────────────────────────
    Algorithm: DeepSORT

    Components:
    • Kalman Filter → Predict movement
    • Hungarian Algorithm → Optimal matching
    • Re-ID Features → Appearance similarity

    Capability:
    • Maintains ID through occlusions
    • Handles multiple persons simultaneously
    • Real-time processing

SLIDE 8: CHALLENGES & SOLUTIONS
──────────────────────────────────────────────────────────────────────────
    Challenge 1: Training from Scratch Failed
    • Problem: 0% confidence on all detections
    • Root Cause: Class imbalance
    • Solution: Transfer learning (YOLOv5)

    Challenge 2: Validating Model Quality
    • Problem: Low loss ≠ good performance
    • Solution: Similarity distribution analysis

    Challenge 3: Colab Disconnections
    • Problem: Lost training progress
    • Solution: Auto-save every epoch to Drive
